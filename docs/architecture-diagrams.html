    httpd --> uiassets
    proc --> file
    proc --> ollamasrv
    proc -.->|opcional| cloudllm
    proc -->|HTTPS| li

Sem servidores, sem orquestração: um executável e um arquivo de banco. Ollama é um serviço local opcional; LLM em nuvem é opcional via chave própria.

Sequência de Publicação (Agendada)

sequenceDiagram
    actor U as Usuário
    participant UI as UI (React)
    participant API as API (Go)
    participant DB as SQLite
    participant SCH as Scheduler
    participant LI as API LinkedIn

    Note over U,LI: Publicação agendada
    U->>UI: Define post + data/hora
    UI->>API: POST /api/schedule
    API->>DB: grava scheduled_post (status=pending)
    API-->>UI: 201 Created

    loop a cada tick
        SCH->>DB: busca posts vencidos (pending)
        DB-->>SCH: post(s) due
        SCH->>DB: lê + descriptografa token OAuth
        alt token expirado
            SCH->>LI: refresh token
            LI-->>SCH: novo access token
            SCH->>DB: grava token atualizado
        end
        SCH->>LI: POST /ugcPosts (w_member_social)
        LI-->>SCH: 201 + URN do post
        SCH->>DB: status=published, salva URN
    end

O scheduler verifica periodicamente posts vencidos, renova o token se necessário e publica via API oficial, registrando o resultado.

Modelo de Dados (SQLite)

erDiagram
    DRAFTS ||--o{ DRAFT_VERSIONS : "tem"
    DRAFTS ||--o| SCHEDULED_POSTS : "pode gerar"

    DRAFTS {
        int id PK
        string title
        string source_description
        string content
        string status
        datetime created_at
        datetime updated_at

    DRAFT_VERSIONS {
        int id PK
        int draft_id FK
        string content
        string generated_by
        datetime created_at
    }
    SCHEDULED_POSTS {
        int id PK
        int draft_id FK
        string content
        datetime scheduled_for
        string status
        string linkedin_urn
        string error
        datetime created_at
    }
    OAUTH_TOKENS {
        int id PK
        string provider
        blob access_token_enc
        blob refresh_token_enc
        datetime expires_at
        datetime updated_at
    }
    SETTINGS {
        string key PK
        string value
    }

Esquema mínimo para rascunhos com versionamento, agendamentos, tokens criptografados e configurações.
